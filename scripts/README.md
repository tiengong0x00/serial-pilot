# 脚本目录 (Scripts)

存放"脚本命令"要调用的外部脚本。Serial Pilot 通过系统 shell 执行你在脚本命令里填写的整行命令，可用来做串口收发之外的辅助动作（切电源、驱动继电器、调用设备工具等）。

## 调用约定

- **执行方式**：应用直接执行你填写的整行命令，例如 `python hello.py COM3 hello`；脚本名之后的内容作为普通命令行参数（argv）传入。
- **工作目录**：固定为脚本所在目录，可用相对路径引用同目录文件。
- **成败判定**：退出码 `0` = 成功，非 `0` = 失败。
- **超时**：上限 300 秒，`stdout` / `stderr` 会显示在执行日志中。
- **解释器**：命令行里怎么写就怎么执行，需要 `python` / `node` 等在系统 PATH 中可用。

## 参考脚本

- **`hello.py`** —— 零依赖（仅标准库）最小示例：打印 `Hello Serial Pilot` 并回显传入参数。作为编写自己脚本的模板。

  在脚本命令里填：`python hello.py COM3 hello`，即可在执行日志看到问候与参数回显。
