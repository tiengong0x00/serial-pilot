## 优化方案对比

### 方案 A：精简图标（推荐）
**理念**：减少视觉噪音，突出核心信息

#### 优化点：
1. **移除命令类型图标** - AT/URC/脚本可用颜色+文字区分，不需要专门图标
2. **状态图标仅在非空闲时显示** - 默认空闲不需要时钟图标占位
3. **拖拽手柄悬浮显示** - 不拖拽时隐藏，鼠标悬停才显示
4. **增加视觉层次** - 用例名称加粗，命令内容常规字重

```
优化后效果：

┌─────────────────────────────────────────────────────────┐
│ 查询信号强度                                      [▶运行]│
│   AT+CSQ                                       [▶发送]│
│   ✓ AT+CREG?                                  [▶发送]│
│ 网络注册                                          [▶运行]│
│   AT+CGREG=1                                   [▶发送]│
│   +CGREG: 1                  (URC守护)         [▶发送]│
└─────────────────────────────────────────────────────────┘

特点：
- 拖拽手柄 hover 时才显示（减少常驻图标）
- 状态图标只在运行中/成功/失败时显示
- URC/脚本用标签文字替代图标
- 用例名称字重更重，视觉上更突出
```

---

### 方案 B：左侧勾选框 + 简化图标
**理念**：用勾选框替代 selected 状态的虚框边框

#### 优化点：
1. **左侧增加勾选框** - 替代当前 selected 状态用的虚线边框
2. **命令类型用颜色区分** - 不同命令类型用不同颜色标记
3. **状态图标合并** - 成功/失败用小圆点颜色表示

```
优化后效果：

┌─────────────────────────────────────────────────────────┐
│ ☑ ≡ 查询信号强度                                  [▶运行]│
│   ☑ ≡ 🕐 AT+CSQ                               [▶发送]│
│   ☑ ≡ • AT+CREG?                              [▶发送]│
│ ☑ ≡ 网络注册                                      [▶运行]│
│   ☑ ≡ AT+CGREG=1                              [▶发送]│
│   ☑ ≡ +CGREG: 1                               [▶发送]│
└─────────────────────────────────────────────────────────┘

特点：
- 左侧勾选框明确显示启用/禁用状态
- • = 小圆点，用颜色表示状态（绿=成功，红=失败）
- 勾选框点击切换 selected，行点击选中
```

---

### 方案 C：极简模式（激进）
**理念**：只保留必要元素

#### 优化点：
1. **完全移除拖拽手柄** - 改用整行拖拽（鼠标样式提示）
2. **移除命令类型图标** - 用文字颜色区分
3. **状态用背景色** - 运行中=黄底，成功=绿底，失败=红底
4. **按钮图标化** - 运行按钮改为纯图标按钮

```
极简效果：

┌─────────────────────────────────────────────────────────┐
│ 查询信号强度                                           ▶│
│   AT+CSQ                                             ▶│
│   AT+CREG?                                           ▶│ ← 绿色底色（成功）
│ 网络注册                                               ▶│
│   AT+CGREG=1                                         ▶│
│   +CGREG: 1                   (URC)                  ▶│
└─────────────────────────────────────────────────────────┘

特点：
- 整行作为拖拽热区
- 状态用行背景色表示
- 最大化内容显示空间
```

## 推荐方案：方案 A（精简图标）

### 为什么推荐方案 A？

✅ **优点**：
1. **减少视觉噪音** - 移除冗余图标，界面更清爽
2. **保留必要信息** - 状态在需要时仍然显示
3. **改动最小** - 基于现有结构优化，不需要大改逻辑
4. **学习成本低** - 用户无需学习新的交互模式

⚠️ **注意事项**：
- 拖拽手柄 hover 显示需要配合明确的拖拽热区
- URC/脚本命令需要用文字标签清楚标识
- 状态图标的显示/隐藏需要平滑过渡，避免抖动

## 实现要点（方案A）

### 1. 拖拽手柄 hover 显示
```tsx
<button
  className={cn(
    "cursor-grab active:cursor-grabbing text-gray-300 hover:text-gray-500",
    "opacity-0 group-hover:opacity-100 transition-opacity"  // 新增
  )}
  {...attributes}
  {...listeners}
>
  <GripVertical style={{ width: iconSize, height: iconSize }} />
</button>
```

### 2. 状态图标条件显示
```tsx
{/* 只在非 pending 状态显示图标 */}
{cmd.status !== 'pending' && <StatusIcon status={cmd.status} isPaused={isPaused} />}
```

### 3. 命令类型标签（替代图标）
```tsx
{/* URC 守护命令显示标签 */}
{cmd.type === 'urc-guard' && (
  <span className="text-xs px-1.5 py-0.5 bg-purple-100 text-purple-700 dark:bg-purple-900 dark:text-purple-300 rounded">
    URC
  </span>
)}

{/* 脚本命令显示标签 */}
{cmd.type === 'script' && (
  <span className="text-xs px-1.5 py-0.5 bg-orange-100 text-orange-700 dark:bg-orange-900 dark:text-orange-300 rounded">
    脚本
  </span>
)}
```

### 4. 用例名称加粗
```tsx
<span className={cn(
  'flex-1 truncate font-semibold',  // 添加 font-semibold
  textSizeClass,
  !case_.selected && 'text-muted-foreground'
)}>
  {case_.name}
</span>
```

## 其他微优化建议

### 1. 运行按钮视觉优化
- **当前**：绿色文字 + Play 图标
- **建议**：改为圆角矩形按钮，hover 时高亮
- **效果**：更像"真正的按钮"，可点击性更强

### 2. 选中状态优化
- **当前**：浅色背景（accent）
- **建议**：左侧增加 3px 蓝色竖线标记
- **效果**：选中状态更明显

### 3. 多选状态优化
- **当前**：蓝色背景（较浅）
- **建议**：左侧多色竖线 + 半透明蓝色背景
- **效果**：与单选区分更明显

### 4. 禁用状态优化
- **当前**：整行 opacity-50 + 虚线边框
- **建议**：仅文字灰色，移除虚线边框
- **效果**：减少边框噪音

## 总结

| 方案 | 适合场景 | 优先级 |
|------|---------|-------|
| **方案A（精简）** | 希望清爽但保持熟悉感 | ⭐⭐⭐⭐⭐ 强烈推荐 |
