实现细节

1. 按钮样式

  • • 使用 Columns2 图标（左右分栏）
  • • 未激活：灰色，hover 时变紫色
  • • 已激活：紫色（与时间戳按钮一致）

2. 状态管理

  • • 新增状态：dualTerminalEnabled: boolean
  • • 持久化到 localStorage
  • • 双串口连接时自动设为 true

3. 渲染逻辑

  • • dualTerminalEnabled === true：显示双终端布局
  • • dualTerminalEnabled === false：显示单终端（合并模式）
  • • P2 未连接时显示占位文案

4. 移除旧逻辑

  • • 删除 terminalMode 状态（merged/split）
  • • 删除左侧的「合并/分栏」按钮组
  • • 删除 P2 断开时的自动切换逻辑
