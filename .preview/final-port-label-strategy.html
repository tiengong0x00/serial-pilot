最终端口标签显示策略

只有合并显示 + 双串口连接时才显示 [P1] / [P2] 标签

✅ 最终方案

const showPortLabel = !dualTerminalEnabled && p1_connected && p2_connected;

规则：仅当 单终端模式（合并显示） 且 双串口同时连接 时显示标签

原因：合并显示时两个串口消息混在一起，需要标签区分；分栏显示时左右栏已明确标注端口，无需重复

场景 1：单串口 + 单终端

P1 已连接 P2 未连接 🔘 单终端
[RX] AT+CGMR
[TX] OK
[RX] AT+CSQ

❌ 不显示端口标签（只有一个串口）

场景 2：单串口 + 双终端

P1 已连接 P2 未连接 🔵 双终端
P1
[RX] AT+CGMR
[TX] OK
P2 未连接

❌ 不显示端口标签（只有一个串口）

场景 3：双串口 + 单终端（合并）⭐

P1 已连接 P2 已连接 🔘 单终端
[P1] [RX] AT+CGMR
[P2] [RX] AT+CGMR
[P1] [TX] OK
[P2] [TX] OK

✅ 显示 [P1]/[P2] 标签（需要区分来源）

场景 4：双串口 + 双终端（分栏）

P1 已连接 P2 已连接 🔵 双终端
P1
[RX] AT+CGMR
[TX] OK
P2
[RX] AT+CGMR
[TX] OK

❌ 不显示端口标签（左右栏已标注端口）

设计思路：

  • • 单串口场景：无论单终端还是双终端，消息来源都是唯一的，无需标注 [P1]
  • • 双串口 + 合并显示：两个串口消息混在一起，必须用 [P1]/[P2] 区分
  • • 双串口 + 分栏显示：左右栏已用端口标题明确区分，消息无需再重复标注

代码实现

1. 端口标签显示逻辑

// 仅在单终端（合并）模式且双串口连接时显示端口标签
const showPortLabel = !dualTerminalEnabled
  && connectionStatus.p1_connected
  && connectionStatus.p2_connected;

2. 双终端自动激活逻辑

// P2 连接时，如果还未开启双终端，自动激活
useEffect(() => {
  if (connectionStatus.p2_connected && !dualTerminalEnabled) {
    setDualTerminalEnabled(true);
  }
}, [connectionStatus.p2_connected]);

3. 终端显示模式

// 双终端开启时显示左右分栏，否则合并显示
{dualTerminalEnabled ? (
  // 左右分栏：P1 左，P2 右
  <div className="flex">
    <P1Terminal />
    <P2Terminal /> {/* P2 未连接时显示占位 */}
  </div>
) : (
  // 合并显示：所有消息按时间排列
  <MergedTerminal showPortLabel={showPortLabel} />
)}

✅ 方案确认

端口标签显示规则：

showPortLabel = !dualTerminalEnabled && p1_connected && p2_connected

即：仅当合并显示 + 双串口连接时才显示 [P1] / [P2] 标签

核心特性：

  • ✅ 工具栏右侧增加双终端图标按钮
  • ✅ 默认单终端，双串口连接时自动激活
  • ✅ 单串口可手动开启双终端（提前布局）
  • ✅ 断开串口不影响按钮状态
  • ✅ 只有合并显示+双串口时才显示端口标签
